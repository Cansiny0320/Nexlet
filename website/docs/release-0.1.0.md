# Nexlet 0.1.0 预览版

首个可下载预览版，提供 Windows x64、macOS Apple Silicon 与 macOS Intel 安装包。

- 搜索应用与快捷方式，查看文本、图片和文件路径剪贴板历史。
- 使用计算稿纸、JSON 格式化、时间戳、URL / Base64、UUID 与网页快开。
- 通过 Nexlet Plugin API v1 开发和加载本地插件；附带 `hello-nexlet.nexlet` 示例。

默认使用 Alt+Space 唤起。快捷键冲突时可在设置中更改。

这是预览版：Windows EXE 未签名；macOS DMG 使用 ad-hoc 签名，尚未公证。自动回贴需要 macOS 辅助功能权限。各平台已通过 CI 构建与打包后启动检查，macOS 真机使用与最低系统版本尚未完成全面验收。

产物来自提交 `6277f6782f194cd8c1b23eeaa7ae4e722f4136e0`，对应 [成功的 CI 构建](https://github.com/Cansiny0320/Nexlet/actions/runs/38157028460)。安装包与示例插件的 SHA-256 已核对，校验值见附件 `SHA256SUMS.txt`。
