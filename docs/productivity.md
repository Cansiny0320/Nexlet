# 效率功能使用说明

这些功能从 Nexlet v0.2.42 开始提供。请先更新主程序，再在插件市场更新对应插件。

1. **快捷短语**：搜索“快捷短语”，创建名称、分组和正文。变量支持 `{{date}}`、`{{date:YYYY-MM-DD HH:mm:ss}}`、`{{clipboard}}`、`{{input:姓名}}`；`\{{` 输出字面量 `{{`。填写变量后点击“预览”，再复制、回贴或继续处理。保存的短语会成为独立指令，可固定、设置别名和快捷键。
2. **继续处理**：在 JSON、编码、时间戳、稿纸、快捷短语及已适配插件的结果旁点击“继续处理”，回到启动器选择下一工具。文本、HTML、图片和文件直接交接；返回源工具可恢复上次状态。
3. **配置文件**：设置中导出 `.nexlet.jsonc`，可在编辑器中修改。导入时先预览差异，勾选类别再应用；可撤销上一次导入。插件清单仅供核对。API Key、历史正文、图片、工具草稿和任意插件私有数据库不在导出中；路径、Prompt 等配置本身仍可能含私人内容。
4. **工作区**：搜索“工作区”，按顺序添加应用、目录、编辑器、终端或网页。编辑器可指定程序与参数；目录作为独立参数传递。可以运行全部、单独运行或只重试失败项；取消停止尚未启动的项目，不关闭已经启动的应用。
5. **图片文字搜索**：从插件市场安装离线 OCR 1.1.0 或更新版本后，在剪贴板图片动作中选择“识别图片文字”，或添加本地图片进行识别。在设置中可启用收藏图片自动识别。任务串行执行，可取消或清除识别文本；清除索引不删除原图，删除历史不会被迟到任务恢复。
6. **AI 动作**：配套插件提供解释报错、润色、提炼待办和生成提交说明。先填写模型、服务地址和 API Key，可编辑 Prompt 或添加动作。点击运行后才发送内容，支持流式输出和取消。密钥交给宿主 secrets 管理，不进入配置导出；输出不会自动执行。
7. **工具状态**：本次运行内切换工具会保留输入、结果、选项和滚动位置。设置中可开启跨重启恢复，也可清除草稿。独立窗口与主窗口隔离，跨重启只恢复主窗口草稿。普通草稿不额外加密，敏感临时输入使用完可清除。
8. **富文本历史**：文本历史可同时保存 HTML。默认复制/回贴保留格式，也可选纯文本动作。历史表格通过“继续处理”交给文字表格转图片；预览不会执行 HTML。
9. **动作菜单**：在启动器、剪贴板、文件和工具结果中按 `Cmd/Ctrl+K`，或打开右键菜单。用方向键选择，`Enter` 执行，`Escape` 返回并恢复焦点。
10. **搜索**：支持轻量英文错拼、文字/拼音匹配高亮及本地关键词偏好。精确匹配优先；只学习普通命令名称查询，不学习带入正文。设置中可以清除学习记录。
11. **记录控制**：设置中暂停记录 15 分钟、配置排除的前台应用，或预览并清理一个时间范围。收藏默认保留。Wayland 等无法可靠识别来源的环境不能保证按应用排除。
12. **文件预览**：选中搜索结果即可预览图片或 UTF-8 文本，用方向键切换。文本最多读取前 256 KiB，图片最多 20 MiB / 3600 万像素；不支持的文件显示原因，不执行脚本、HTML 或 Markdown。
