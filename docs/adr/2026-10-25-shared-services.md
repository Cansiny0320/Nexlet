# 共享服务与账号同步边界

状态：2026-10-25 已批准并实施；真实平台验收范围另记。

共享 AI 模型配置由主进程持有，密钥与插件私有 secrets 使用不同命名空间。新流事件单独定义，旧 AI API 不改变合同。提供商（provider）是插件对 OCR 或 translation 能力的声明，包含稳定 ID、版本、local/cloud 属性、入口与配置 schema；它不是 AI 供应商的别名。宿主默认提供商只决定本次调用目标，失败不能隐式跨越本地／云端边界。

账号服务独立部署，Better Auth 管理身份与会话，PostgreSQL 管理同步记录。客户端先持久化本地内容和 outbox，再比较服务端 revision。mutationId 表示一次幂等写入；tombstone 表示服务端删除；cursor 仅表示拉取进度。冲突保留 local 与 remote 两份候选，用户明确选值后再写入。正文加密属于服务端存储加密，不称为端到端加密。

配置导入导出继续是用户操作的快照。同步使用显式字段适配器，不上传任意 documents 或插件数据库。路径／快捷键属于设备映射，先确认再应用；插件清单是安装建议，不能直接安装、启用插件或扩大权限。剪贴板类别独立选择且默认关闭。
