Nexlet 0.2.2 新增插件市场、JSON 美化与差异对比、Windows 内置文件搜索，并修复搜索初始化状态和快捷方式图标显示。

## 新增与改进

- 插件市场支持浏览、安装和更新本地插件，插件数据独立保存；内置工具可以直接使用。
- JSON 工具提供树形美化、折叠展开和双栏差异对比，绿色表示新增，红色表示删除。
- Windows 随包提供 Everything 便携引擎，无需另装。首次输入搜索词后建立本地索引，可在设置中指定索引目录。
- 设置中新增开机自启动，开启后登录系统时在后台运行。
- 标题栏增加拖动手柄和可拖动的工具名称；最小化后唤起会恢复窗口并请求前置和聚焦。

## 修复

- 文件搜索未输入内容时保持待输入，不再发起空查询。
- 首次索引未完成时显示等待提示并自动重试，不再误报“搜索失败”；清空搜索框后忽略过期查询结果。
- 正确读取飞书等快捷方式指定的 ICO 图标，失效资源回退到程序图标。

## 下载与更新

- Windows x64：`Nexlet-0.2.2-Windows-x64.exe`，单文件便携版。
- Intel Mac：`Nexlet-0.2.2-macOS-x64.dmg`。
- Apple Silicon Mac：`Nexlet-0.2.2-macOS-arm64.dmg`。
- `hello-nexlet.nexlet` 是示例便笺插件；`SHA256SUMS.txt` 可用于核对下载文件完整性。

更新前请从托盘退出旧版 Nexlet，再打开新版本。已有本地数据沿用原数据目录。Windows 便携 EXE 请放在固定位置；移动文件后如需自启动，请在设置中重新开启。

## 平台说明

- Windows 包没有数字签名。Everything 首次索引可能需要较长时间，仅索引当前用户可访问的文件，不安装系统服务。
- macOS 暂不提供 Everything 文件搜索；DMG 使用 ad-hoc 签名，没有 Apple Developer ID 签名或公证，系统可能拦截首次打开，需要在系统设置中明确允许。
- macOS 自动回贴需要辅助功能权限。CI 启动检查不代表已完成真实桌面回贴、自启动及系统授权流程验收。
