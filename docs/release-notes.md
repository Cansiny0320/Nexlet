Nexlet 0.2.43 精简界面中的重复标题、标签和说明，让常用操作更直接。

## 优化

- 移除设置、快捷短语、工作区、编码转换和网页快开中的重复页面标题，以及短语和工作区的介绍性文案。
- 精简重复的“预装”“已启用”和“未分组”标签，保留禁用、不可用和快捷键状态。
- 插件版本与安装来源移入详情，开发目录标记和权限信息仍可查看。
- 搜索没有内容匹配项时隐藏空分组标题；插件市场保留缓存时间，移除常驻托管说明。
- 压缩设置中的说明，保留本地存储、配置导出范围和离线 OCR 依赖等必要信息。
- 同步简体中文、繁體中文和 English，并保留页面标题的无障碍语义。

## English

Nexlet 0.2.43 removes duplicate page headings, introductory copy, and repetitive status labels. Plugin versions and installation sources are available in the details view. Empty content-match groups are hidden, and settings explanations are shorter while retaining storage, export, and offline OCR requirements. The changes cover Simplified Chinese, Traditional Chinese, and English, with accessible page headings preserved.

## 下载

- Windows x64：安装包 Nexlet-0.2.43-Windows-x64-Setup.exe；便携包 Nexlet-0.2.43-Windows-x64.exe。
- Apple Silicon Mac：Nexlet-0.2.43-macOS-arm64.dmg。
- Intel Mac：Nexlet-0.2.43-macOS-x64.dmg。
- Linux x64：Nexlet-0.2.43-Linux-x86_64.AppImage、Nexlet-0.2.43-Linux-amd64.deb。
- Linux arm64：Nexlet-0.2.43-Linux-arm64.AppImage、Nexlet-0.2.43-Linux-arm64.deb。
- macOS ZIP、blockmap 和 latest*.yml 用于应用内更新；SHA256SUMS.txt 提供文件校验值。

手动安装前请先完全退出旧版。现有本地数据继续使用原用户目录。

Windows 暂无代码签名；macOS 使用固定签名身份，但未经 Apple Developer ID 签名与公证。Linux 桌面集成以 X11 为主要验证环境，Wayland 的已知限制见仓库 docs/linux.md。
