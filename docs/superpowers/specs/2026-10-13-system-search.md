# 系统搜索与操作补齐

2026-10-13 用户已批准：macOS、Windows 补齐系统应用、设置入口、系统操作，并验证关键词和执行行为。

## 行为

- macOS 应用使用系统本地化显示名，原文件名保留为英文别名；增加 CoreServices/Applications 和 Finder 等明确可启动应用。路径 ID 不变，保留固定项与最近使用。
- macOS 注册显示、声音、网络、蓝牙、打印机、键盘、辅助功能、隐私、更新等常用设置入口。Windows 以 uTools 的 67 项设置为对照，按当前官方 URI 与 OS 版本注册有效入口；不复制已失效入口。
- 系统命令独立于应用计数，支持中文、英文、全拼、首字母、带空格和连续英文别名。区分睡眠操作与电源设置。
- 两端提供锁屏、睡眠、重启、关机、注销、显示桌面。睡眠、重启、关机、注销须主进程确认，默认取消；拒绝未知 ID、并发重复执行。
- 主进程持有固定操作白名单，renderer 仅传命令 ID。取消保留搜索，失败显示错误且不记录成功；成功才记录最近使用、隐藏启动器。
- 不新增任意命令执行能力，不触发真实电源操作，不发布或修改 Git 远端。

## 验收

索引和关键词矩阵覆盖中英文、别名、拼音、系统设置与动作；平台隔离、版本筛选、取消、成功、失败与重复触发均有测试。macOS 实际应用元数据和 Electron 搜索链路验证；Windows 原生执行使用替身，真机限制明确报告。
