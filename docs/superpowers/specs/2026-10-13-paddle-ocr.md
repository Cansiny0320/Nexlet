# PaddleOCR.js + PP-OCRv6 离线 OCR 替换

用户已批准：替换现有 OCR，多测几张真实截图，确认效果后打包安装到本机。

## 行为与实现
- 用 @paddleocr/paddleocr-js 0.4.2 与 PP-OCRv6_small_det / PP-OCRv6_small_rec 替换 Tesseract。
- 模型、OpenCV 和 ONNX Runtime WASM 随应用分发，固定模型 SHA-256；识别不访问外网、不上传图片。
- 浏览器 SDK 在独立隐藏的 sandbox renderer 中运行。主界面保持响应；取消、超时、关闭会销毁识别进程。主进程只发送已校验的图片，接收进度与纯文本结果。
- 保留现有截图、选图、拖图、粘贴、旋转、编辑、复制、继续搜索及剪贴板冲突保护。
- 保留上一轮录屏授权引导和完整悬浮提示修复。

## 验收与边界
- 在用户提供的付款截图上核对金额、日期、标签；补充至少四张不同真实界面截图，人工整理关键文字与实际输出对比，不以合成大字图代表质量。
- 测试取消、晚到结果、空白图片、缺失模型、超时，以及本地资源边界和离线运行。
- 本机 macOS arm64 包完成签名、包内实际 OCR、备份安装与启动检查。Windows/Linux 不声称完成实机验证。
- 不添加云 OCR、翻译、表格还原或方向分类模型。保留手动旋转。
- 不 commit、push、发布或改动其他会话工作。
