## 产品行为

1. **快捷短语**：创建、分组、搜索、编辑、删除常用文本；日期、剪贴板及手填变量；预览后复制或回贴；通过稳定指令 ID 支持固定、别名、快捷键。
2. **继续处理**：内置工具及官方 OCR、翻译、文字转图、AI 动作的结果可交给匹配工具。支持文本、图片、文件及可选 HTML，保留源工具状态；由用户选择下一步，不自动串行执行任意插件。
3. **配置导入导出**：本地可编辑 `.nexlet.jsonc`，支持注释和格式校验。包含宿主设置、指令偏好、固定项、网页入口、面板设置、快捷短语、工作区、AI 动作定义及插件清单。导入前展示差异，按类别决定应用或保留；保存可撤销的原配置。排除 API Key、剪贴板正文、图片、工具草稿和插件私有数据库。路径、插件及快捷键平台差异需提示；不自动安装插件或执行工作区。
4. **工作区**：应用、目录、编辑器、终端、网页的有序集合；可单独运行、整体运行、重试失败项。使用结构化程序和参数，路径作为参数，不拼接执行用户文本。
5. **图片文字搜索**：对历史图片、收藏图片及主动添加图片建立离线 OCR 索引。手动识别；可选收藏后自动识别；串行、可取消、可清除索引。复用离线 OCR 插件，任务与可见 OCR 会话独立；删除图片后不能被迟到任务重建。
6. **AI 动作**：官方插件预置解释报错、润色、提炼待办、生成提交说明；可创建修改 Prompt、模型、服务地址；复用现有 AI provider、密钥和任务能力，流式输出、取消、复制、回贴、继续处理。不自动执行输出文本。
7. **工具状态保留**：切换恢复输入、输出、选项和滚动位置；内置工具及相关官方插件适配快照；本次运行默认保留，可选跨重启恢复。独立窗口保持隔离，新输入是明确激活，不误用旧输入；退出停止后台任务。
8. **富文本剪贴板历史**：文本记录保存可选 HTML，支持保留格式和纯文本复制/回贴，历史表格继续转图；保留旧历史可读性，不向摘要页传输完整 HTML，不执行 HTML 或加载外部资源。
9. **统一动作菜单**：`Cmd/Ctrl+K` 和右键统一呈现适用动作；覆盖启动器、剪贴板、文件及工具结果；键盘导航、Escape、焦点恢复、输入法保护。保留已有右键能力。
10. **搜索优化**：轻量拼写容错、匹配高亮、本地关键词偏好；精确匹配优先，支持清除学习记录，不采集正文输入或上传记录。
11. **记录控制**：定时暂停、按前台应用暂停、按时间范围清理；显示范围和数量，收藏默认保留。未知来源不冒充已识别应用；Wayland 能力限制明确。
12. **文件预览**：图片、纯文本/代码/JSON/Markdown，键盘切换；限制文件读取和图片解码资源；失效路径、二进制、大文件提供明确状态，不执行文件内容。

## 边界与复用

- **配置**是用户定义的可迁移行为；**会话**是工具的临时输入和视图；**结果**是用户主动交接的数据；**历史**是剪贴板持久化记录。四者分别存储，导出不混入会话与历史。
- 宿主通过现有 oRPC/preload、CommandRegistry、LaunchInputs、SQLite Store 和插件隔离机制提供能力。SDK 添加可选扩展，旧插件保持可用，官方插件提高最低宿主版本。
- 新增管理界面复用现有表单、Base UI、Lucide、配色、字体和列表样式，不另建视觉系统。编辑区与结果预览清楚分开，错误保留在相关表单中。
- 文本结果不经过系统剪贴板中转；文件、图片维持 owner/token 生命周期。异步回调检查请求代次，取消后不能覆盖新输入。
- OCR 无任务时不轮询或保留模型；大数据异步处理。文件预览只读取当前选择，快速切换忽略过期结果。
- 配置新增结构及历史字段向后兼容；新存储 key 独立命名。回滚代码后旧版本忽略新 key/字段；导入可恢复前一份配置。
- 保持简体中文、繁体中文、English 三语完整。

## 验收

- 快捷短语变量预览、验证、Unicode、缺失参数、复制与回贴；工作区有序执行、单项失败、取消及重试不重复成功项。
- JSON → 剪贴板 → JSON、独立窗口及官方插件恢复；新输入覆盖策略；重启开关、草稿清除；取消请求和退出清理。
- OCR → 翻译、Base64 → JSON、富文本历史 → 图片、AI → 下一工具；缺失/禁用插件与过期授权。
- 配置导出可读、修改后可导入；差异、类别选择、非法输入、跨平台警告、撤销；密钥与私人历史不泄露。
- 剪贴板 HTML、纯文本、多选、去重、摘要体积；定时暂停到期、应用排除、收藏保护及按时段清理。
- OCR 索引手动、收藏自动、清除、取消、删除竞态与无插件提示；真实离线图片识别搜索。
- 错拼召回、精确结果优先、偏好只影响匹配结果、学习清除、高亮与中英文；预览边界和快速切换。
- 主仓检查、单测、构建、相关 Electron 测试及三语浅深色截图；插件类型、单测、构建和真实宿主集成测试。实际平台为 macOS，Windows/Linux 系统行为如无法实测需单独记录，不把模拟测试写成实机验收。
