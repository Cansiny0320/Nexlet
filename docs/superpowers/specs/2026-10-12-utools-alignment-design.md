# uTools 行为对齐（已批准）

2026-10-12 用户批准：「按这个方案实现，保留自有 SDK，外部插件默认内嵌，两批都做完并验证。」

## 依据与范围

参考本机 uTools 7.8.0 ASAR 的 REA 静态分析及原始包代码，Evidence `ev_180f6ab982b903b527d34c9251e26052bf4b00471294e279703e81ce764962eb`，ASAR SHA-256 `dfb382d5a8daba34c06dd9a035da66f896c0b53d3bc85b2031e164fce08ad272`。参考链路包括内容匹配、插件视图内嵌及转移、ready/enter/out/detach 事件。自动分析覆盖 partial（语义图内存限制）；4 个 unpacked 原生文件声明哈希不一致，未据此推断原生行为。未运行 uTools 动态验收。

这是 Nexlet 自有实现，不复制 uTools 代码、品牌、服务，也不承诺 `.upx` 或 `window.utools` 兼容。继续使用现有 SQLite、稳定插件 ID、独立存储、权限确认、sandbox、contextIsolation、无 Node 和禁止直接联网的插件边界。保留用户现有本地签名相关改动。

## 第一批：输入与匹配

- 启动器维护输入快照：文本、图片或文件，包含 ID 和来源（输入、粘贴、拖放）。查询异步结果绑定输入代次，过期结果不可覆盖新输入或执行新内容。
- 图片/文件保留为输入卡片，允许继续键入关键词筛选处理功能。取消输入不写系统剪贴板；只有选择「收进剪贴板」等明确操作才写入。
- 内置计算、URL、JSON、剪贴板匹配迁移到统一宿主入口；保留现有关键词、中文拼音与最近使用排序。
- 插件 feature 可选声明 `matches`：文本长度、正则、图片、文件类型/扩展名/数量。旧 `apiVersion:1`、`code/name/keywords` manifest 继续有效。关键词命中优先，内容匹配随后，同一个功能去重，最近使用作为同级排序依据。
- 正则匹配在可终止 worker 中执行；限制规则数、模式/输入长度，设置单规则与批次预算，新查询取消旧查询，坏规则不阻塞普通搜索。
- 用户选择插件后，仅该插件会话获得本次图片/文件的只读资源 token。宿主验证 token、调用者、输入与会话；限制数量/大小，检测文件移动/替换/修改，目录不授予递归读取。新进入替换旧授权，退出、停用、更新、卸载或崩溃时释放。
- 不自动读取外部应用选区、不引入任意文件系统权限。

## 第二批：会话与窗口

- 功能指令决定做什么；会话拥有 renderer、输入授权与生命周期；窗口只是呈现位置。每个外部插件最多一个会话。
- 外部插件默认使用 `WebContentsView` 嵌入主窗口内容区；宿主标题栏、返回、分离与关闭属于可信宿主，不向插件开放 `host-api`。
- 分离转移同一 view/webContents/session，不 reload、不重新初始化。再次启动已分离插件时聚焦原独立窗口并交付新输入。
- 新 SDK 提供 context/输入读取和 ready/enter/out/detach 事件。ready 每个 renderer 一次，enter 每次显式启动一次，detach 只表示呈现位置改变。旧 `info()` 和 `onActivate` 保留字符串 payload 与再次激活语义。
- 临时隐藏主窗口保留会话；返回首页、切换到另一个工具或明确关闭结束当前内嵌会话；首版不缓存多个后台插件。停用/卸载/更新/退出/崩溃可靠清理。异步加载迟到不得复活旧会话，旧 closed 回调不得删除新会话。
- 子 view 中的 Escape 与宿主快捷键由主进程处理；窗口缩放和内容尺寸更新 view 边界；宿主模态交互期间隐藏插件 view，避免覆盖确认 UI。
- 内置工具继续为宿主 React 工具，不转换为外部插件。分离采用两阶段交接：冻结输入并获取 snapshot → 目标窗口恢复确认 → 原窗口返回首页；失败保留原页面。
- JSON 保留格式化输入、双栏输入、页签、选项和比较状态；不承诺完整撤销历史。编码/时间戳/UUID 保留输入输出与选项；剪贴板保留搜索、分类和选择；稿纸等待 pending save 成功并保留活动稿纸与编辑位置；文件搜索保留 query 并按目标 caller 重新查询，不转移任意文件操作权限。

## 验收

1. 普通/内容匹配、排序、去重、旧 manifest、非法规则、超时取消与过期结果测试。
2. 真实 Electron 输入/拖放后剪贴板不变；选择插件传入固定上下文，只有被选择插件可读取资源；旧 token、跨插件、已变更文件拒绝。
3. 真实 Electron 内嵌、分离保留 DOM 状态和同一 webContents，重复进入事件次数正确；加载中关闭/停用不复活，崩溃不影响宿主。
4. 新旧插件 SDK、独立数据、权限拒绝、无 Node、网络拒绝、升级/停用/卸载回归。
5. JSON 双栏、编码结果、剪贴板筛选选择、稿纸 pending save 分离恢复；恢复失败与保存冲突保留源页面。文件搜索使用隔离夹具或边界替身验证 caller，不在 macOS 声称验证 Windows 引擎。
6. `npm run typecheck`、`npm test`、`npm run build`、相关 Playwright E2E、`git diff --check`。本地验证与发布严格区分。

## 风险与回滚

新输入只存内存，持久化数据合同不破坏；manifest 可选字段，旧插件不要求升级。卸载/重装保留数据行为不变。主要风险是 Electron view 生命周期、异步事件与状态交接，使用真实应用测试验证。回滚本次相关源码和文档即可，SQLite 无破坏性迁移。不创建 worktree、不 commit/push/发布。
