# Windows 应用目录与图标缓存

用户于 2026-10-16 批准：本次覆盖 Windows。启动先显示本地缓存的应用、快捷方式和已加载图标，再后台更新；保留正常应用、系统工具以及已有卸载/文档过滤规则。

## 行为与边界

- 在首个窗口请求状态前恢复目录、去重别名、图标来源和指纹；固定及最近使用 ID 沿用现有映射，不改用户记录。
- 每次启动后台扫描；期间旧目录可用，成功后整体替换。非缺失类目录读取错误或 Windows 应用查询失败保留旧快照，不能把失败当作空结果覆盖缓存。
- 指纹包含快捷方式、目标程序和自定义图标资源的路径及文件元数据；仅在后台检查。未变化图标复用，变化项按需重新提取，删除项回收。失败的图标提取不永久缓存。
- 独立 `catalog-cache.sqlite` 保存有版本和扫描上下文的目录快照与 PNG 图标。上下文包含平台、语言、扫描路径；不兼容上下文或格式不恢复。图标预算 32 MiB，单图最大 512 KiB，目录快照最大 8 MiB，数据库页数设上限；按使用时间回收图标。
- 缓存损坏可重建；缓存不可写时降级到内存和现有扫描，不影响设置、剪贴板、固定记录或启动。
- 扫描期间发生路径/语言变更时串行处理最新请求，过时结果不能提交；图标请求带索引版本校验，迟到结果不能覆盖新图。
- macOS/Linux 保留现有索引方式；不增加远端服务、安装、发布、Git 提交或文件系统常驻监听。

## 压力测试结论

已检查扫描失败、删除条目、重启恢复去重映射、语言/路径变化、旧图标响应、缓存损坏、写入失败及退出时异步工作等边界。沿用现有应用 ID 与启动方式，无新领域概念，无需 glossary 或 ADR。

## 验收

真实 Electron 进程退出后再启动，在后台扫描完成前显示缓存入口与图标；后台扫描更新增删和图标变化；固定/最近记录正确；损坏缓存不阻止启动。单元测试覆盖持久存储限额、上下文/格式验证、失败保留、并发过时响应；既有跨平台和过滤测试继续通过。

## 风险与回滚

后台刷新完成前短暂显示上次目录是预期行为；首次启动或缓存失效时需正常扫描。以文件元数据判断图标更新，不逐个读取程序内容。回滚缓存接入即可恢复原扫描方式；独立缓存可忽略或删除，不需要迁移用户数据库。
