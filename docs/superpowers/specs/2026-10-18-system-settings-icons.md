# 系统设置生成图标

## 已批准的最终设计

用户已确认 imagegen 的 78 项完整设计稿，并要求将所有系统设置图标替换成生成图标。本设计替代先前的 Lucide 分类配色方案。

- 使用已确认的轻立体彩色物件造型；保留原设计的轮廓、颜色和语义。
- 覆盖 Windows 10/11 的 70 个设置 ID 和 macOS 额外的 8 个 ID。
- 使用内置 imagegen 去除设计稿背景与标签，保留真实 alpha；用本地打包脚本裁出并标准化为独立 PNG。
- 已知系统设置的生成图优先于目录传回的原生图标，确保 Windows/macOS 一致使用已批准设计。
- 未知系统设置继续允许原生图像与通用设置图标兜底。其他应用、工具、插件和系统操作图标保持原行为。
- 沿用现有 ToolIcon 的尺寸、布局、图片渲染和装饰性 alt 属性，不改变跳转、设置数据或目录缓存合同。

## 文件和验收

- assets/artwork/system-settings/ 保存设计稿、透明原稿、生成提示词和裁切清单，不纳入安装包。
- assets/system-settings/ 保存 78 张标准化透明 PNG；src/renderer/system-setting-icons.ts 显式导入，供 Vite 打包。
- scripts/render-system-setting-assets.mjs 可从批准原稿重建资源，保留透明通道并统一视觉占比。
- 自动测试从实际 systemCommands 清单验证覆盖、独立资源、生成图优先级、未知入口兜底和资产可读性。
- Electron 验证固定、最近与搜索入口使用生成图；macOS 原生目录提取保留原有后端测试，但 UI 以生成图为准。
- 视觉检查 24/32/38 px 及深浅主题，确认无文字残片、背景白块、明显边缘杂色或裁切。

## 风险与回滚

- 原稿每个图标约 100 px，覆盖当前 24–38 px 显示和常见 2x 屏幕；不将放大输出描述成新增细节。
- PNG 资源会增加包体；记录标准化资源总大小。
- 回滚仅恢复 ToolIcon 映射及对应资源，不涉及数据迁移。
- 不提交、推送、发布或修改用户真实配置。
