# Nexlet 首版设计（已批准）

批准依据：2026-10-11 用户确认「按这个 UI 图实现就行」，要求搜索包含快捷方式，移除「市场精选」。插件采用 Nexlet 自有 API，功能体验对标 uTools。

## 产品与界面

Windows、macOS 桌面工具；Linux 为可选平台。Electron + React + TypeScript。界面以用户提供的四张 uTools 截图为准，不使用早先青绿色概念图：约 800 px 宽的浮动窗口，顶部输入框；首页最近使用和已固定图标网格，无市场精选；搜索结果按应用/快捷方式/插件指令和内容匹配分组。插件占据同一窗口，也可以分离。

计算稿纸：左侧逐行公式，右侧稿纸历史，结果位于行右下方，底部颜色、锁定、删除、重命名、图片导出、新稿纸。Enter 将结果带入下一行；上下键移动；Ctrl/Cmd+B 备注；多稿纸自动保存。支持四则、括号、幂、百分比和常用数学函数；禁止执行 JavaScript，明确错误与复杂度限制。

剪贴板：顶部搜索；全部/文本/图像/文件/收藏分类；完整宽度的历史列表；右侧复制、粘贴、悬浮中转、独立窗口、设置及清理操作。支持多选合并、收藏、预览、暂停记录、容量/期限清理。捕获服务独立于插件视图，避免关闭视图停止记录。文件记录保留路径，不擅自复制或删除原文件。文本和图片持久化到本机。

首批附加工具：网页快开、JSON 格式化、时间戳、URL/Base64、UUID。主程序提供应用启动、快捷方式检索、中文/拼音/首字母匹配、托盘、主题、全局快捷键、最近与固定列表。文件全文索引、OCR、Markdown、云同步与批量处理为后续批次。

## 架构和数据

- `src/main`：窗口、全局快捷键、托盘、数据存储、剪贴板捕获、平台适配、插件生命周期。
- `src/preload`：对宿主 UI 和第三方插件分别提供严格限定的 IPC API。
- `src/renderer`：主搜索、内置插件界面和设置。
- `src/shared`：数据类型、命令定义与纯逻辑。
- 第三方插件：manifest + HTML/JS/CSS，独立沙箱窗口及 session，通过 Nexlet SDK 请求明确授权的能力；不可访问 Node.js、任意 IPC 或其他插件存储。
- 本机数据：SQLite 元数据、独立图片附件、版本化设置与稿纸。数据库写入事务化，错误不得伪装保存成功。
- Windows 搜索开始菜单和桌面的 `.lnk`、`.url`，以及系统应用；macOS 搜索系统及用户 Applications 中的 `.app`，附加路径通过设置添加。文件/应用路径从已发现的索引选择，不拼接进 shell 命令。

## 关键边界

- 默认快捷键使用 Alt+Space，可配置；已被 uTools 占用时提示冲突，可改 Ctrl+Alt+Space。绝不改动 uTools 的配置。
- 回贴在唤起前记录外部目标；无目标或权限不足时仅允许复制，失败提示保持真实。macOS 辅助功能授权由用户完成。
- 插件安装验证路径、入口、manifest 和大小；拒绝路径穿越、越权能力与伪造调用者。卸载插件数据须单独选择；失败或挂起不应影响主窗口。
- 剪贴板限制条数、单项大小和期限，抑制自身写入重复。默认本地存储，无后台上传或遥测。
- 多显示器定位与缩放须实测；窗口与列表支持键盘导航。
- 安装、分发与真实平台验证分别记录。当前 Windows 可实测；macOS 原生能力和安装包需在 Mac 完成验证，不能以 Windows 构建成功替代。

## 验收

1. 界面对照四张截图，首页没有市场精选；启动器能搜索并真实打开系统快捷方式。
2. `128*3 → 384`，Enter 续算 `384+256 → 640`；小数、括号、幂、除零、非法表达式和重启恢复通过。
3. 剪贴板真实捕获文本/图片/文件；搜索、分类、收藏、多选合并、重启恢复及向外部编辑器粘贴通过。
4. 本地安装示例插件，启停、升级、独立存储及卸载可用；无权限调用被拒绝，坏插件不能使主程序失去响应。
5. 附加工具各有正常、错误输入验证；Windows 可运行并打包；macOS 构建和真机测试如未执行，明确留在交付报告。
