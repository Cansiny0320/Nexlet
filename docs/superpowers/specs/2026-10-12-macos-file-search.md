# macOS 文件搜索

用户已于 2026-10-12 批准 Spotlight 首版方案。

macOS 使用系统 `/usr/bin/mdfind` 查询 Spotlight 索引，Windows 保持 Everything。复用现有文件结果合同、窗口隔离的操作白名单及打开、Finder 定位、复制路径、键盘选择行为。

支持中文文件名、空格分隔的多关键词（同时匹配）、双引号短语、`*` / `?` 通配符和 `ext:pdf` 扩展名筛选。不实现完整 Everything 语法或全文检索。默认查询 Spotlight 可搜索范围；配置目录后仅查询这些目录，配置只限制查询，不改变系统索引。

最多展示 200 条，查询有超时和取消机制，新查询、修改目录及窗口关闭使旧结果失效。参数通过独立进程参数传递，转义 Spotlight 查询字符串。路径以 NUL 分隔，结果去重并读取文件元数据；忽略已删除或无法读取的结果。

macOS 界面显示 Spotlight、支持的输入方式和搜索范围设置。无结果时说明未索引或被排除的文件可能无法找到；失败和超时允许手动重试，不把空结果判定为索引中。不自动调整 Spotlight 配置或权限。

限制：依赖系统索引覆盖和更新速度；本次交付为本地源码和验证，不涉及打包、发布或 Git 远端操作。
