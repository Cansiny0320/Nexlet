# Nexlet 插件市场与工具增强

2026-10-12：用户批准本设计，明确不需要插件下载 SHA-256 校验；另要求预装 Everything 文件搜索。主程序、插件仓库全部公开。官网在主仓库 `website/`，已交给同项目的独立会话实现、验证并用 Sites 公开部署。

## 已批准行为

- 新建 `Cansiny0320/Nexlet-plugins` 公开仓库，维护插件列表、图标、版本和插件包。桌面从该仓库读取列表，用户可安装、手动更新、停用、卸载。
- 插件市场提供“市场 / 已安装”，保留本地包及开发目录入口。已安装来源分为预装、市场和本地。现有剪贴板、计算稿纸、JSON、编码、UUID、时间戳、网页快开等随软件提供，离线可用；宿主系统功能保留当前实现，不伪装成可卸载的外部插件。
- 外部插件继续使用自有 manifest、隔离窗口和显式权限确认。下载不做哈希校验；仍限制来源、请求时间、下载大小，并验证 ZIP 路径、大小、manifest 和 API 兼容性。更新先完成读取与验证，再切换安装记录；失败保留旧版本和独立数据。
- GitHub 仓库不可达时区分缓存列表和刷新失败，不把网络错误显示为空市场；已安装插件继续可用。首版只在用户进入市场或点击刷新时请求列表，不自动下载安装或更新。
- JSON 以一个入口提供“格式化 / JSON 对比”。格式化页参考用户给的 FeHelper 截图：紧凑工具栏、左输入、右解析结果、语法色彩、行号、折叠、复制。对比页左右排列，新增绿、删除红、修改显示旧值与新值。默认忽略对象键顺序，保留数组顺序，清楚显示非法 JSON 的位置。处理在本机完成，不上传 JSON。
- 增加预装 Everything 文件搜索：Windows 上通过官方 ES 接口读取本机 Everything 索引，显示文件名、路径，打开文件、定位目录、复制路径。查询参数作为独立参数传入，不允许搜索文字执行 ES 管理开关。未安装/未运行 Everything 时显示正确状态和官方获取入口；不自动安装服务或修改用户索引。macOS 显示该 Windows 工具不可用。
- README 重写为正式开源项目首页，许可证选择 MIT；第三方组件保留各自许可证。官网使用真实能力、真实下载状态，不编造版本、评分或使用量。

## 数据及安装边界

市场索引使用版本化 JSON；每项包含稳定插件 ID、名称、版本、说明、作者、分类、支持平台、安装包 URL 和可选图标。包内 manifest 的 ID、版本必须与索引一致。包下载仅允许本项目的 GitHub Release 地址及其 GitHub 资产重定向。客户端无 GitHub token，不提供任意镜像源设置。

插件安装记录增加可选来源信息，旧记录按本地导入处理。数据键继续按插件 ID 隔离，卸载默认保留数据。新版不覆盖开发目录插件，也不静默增加权限。插件自身的网络隔离保持不变，市场请求由宿主执行。

JSON 文本长度与嵌套深度设上限，避免编辑器阻塞；格式化保留数字原文，避免大整数精度丢失。对象顺序归一化只用于差异视图，不覆盖输入。新增/删除除颜色外同时有行号区域标记和统计。

## 已查证问题与取舍

快捷方式图标：当前 Electron/Windows 对 `.lnk` 返回同一通用图标。修复为读取 shortcut.icon 或 shortcut.target，注册应用读取 AppxManifest 的本地图标。失效资源不阻止启动器列出条目。

市场不建设账号、支付、评论系统；公开 GitHub 索引与 Release 足以覆盖当前维护和安装要求。预装工具的宿主实现无需迁移到有限权限的外部 SDK。

Everything 依赖 Windows 上正在运行的 Everything 客户端，官方 ES 是 MIT 项目。Nexlet 提供入口与查询适配，不接管其安装、服务和索引设置。

## 验收与回滚

验证列表、缓存、错误状态、安装、取消权限、更新失败保留旧版本、卸载保留数据、错误来源与路径拒绝；JSON 格式化、语法错误、精度、对象顺序、数组顺序、增删改着色；快捷方式真实图标及启动；Everything 查询参数、缺失依赖状态和结果打开边界。保留全部现有测试。

主程序 CI 验证 Windows x64、macOS Intel、Apple Silicon 的打包与启动。Everything 不在 CI 安装系统服务，在线查询视本机可用情况验证并明确范围。

回滚采用还原本次提交、恢复旧版本程序；新安装字段均可选，已有用户数据不迁移或删除。官网会话只写 `website/`，本会话避免暂存其改动。
# Everything 便携引擎补充（用户已批准）

用户明确选择“集成便携引擎，用户无需另装”。Windows 随包提供官方稳定版 Everything 1.4.1.1032 和 ES 1.1.0.38，保留各自许可。首次打开文件搜索时启动 Nexlet 专用实例，配置、数据库和运行文件均位于 Nexlet 用户数据目录。退出 Nexlet 时关闭该实例，不操作用户另外安装的 Everything。

压力测试结论：普通用户无需管理员权限即可使用文件夹索引；NTFS 原生索引需要额外权限，不能将其作为首次运行的隐含前提。本版本默认以普通权限扫描本地固定磁盘中可访问的文件，支持在 Nexlet 调整索引目录，不自动安装服务或修改系统启动项。首轮扫描较慢，界面区分引擎启动、建立索引、空结果与故障。隔离测试只索引临时夹具目录。

验证包括真实便携引擎搜索中文文件名、路径中的空格与逗号、更新索引目录、停止专用实例、缺失二进制的可见错误和打包后启动。回滚可删除该内置引擎接入改动；用户文件不被修改，数据库是可重建的本地缓存。
