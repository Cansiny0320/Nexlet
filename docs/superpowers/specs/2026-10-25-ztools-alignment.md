# Nexlet 功能补齐与公开账号同步

状态：用户于 2026-10-25 明确批准；实现前保存的设计。

## 目标与边界

对齐 ZTools 中有实际价值的功能：统一 AI/OCR/翻译配置、截图编辑与手动滚动长截图、插件市场安装更新体验、PDF/图片批处理/批量重命名插件，以及公开 GitHub 登录和跨设备同步。延续现有界面和受限插件 API，不整体改版。

主仓库 `D:/code/Nexlet`；插件仓库 `D:/code/Nexlet-plugins`。当前会话实施，不创建 worktree，不 commit/push/merge/PR 或发布客户端。用户已批准独立服务部署到现有 Oracle VPS。不可运行干扰用户桌面的鼠标、键盘或真实剪贴板测试。

## 账号与同步

- 面向所有用户开放，GitHub 登录；使用 Better Auth，不实现自有密码认证。
- 使用官方 Device Authorization + GitHub social provider，在系统浏览器登录并明确确认设备，桌面主进程轮询完成。会话由宿主系统密钥存储保护；无法安全持久化时仅保留内存。渲染器和插件拿不到账号会话、GitHub token 或 OAuth secret。
- 提供登录、取消、退出、设备查看/撤销、删除账号。用户 ID 来自服务端验证的会话，不信任客户端声明的 owner。
- 新增独立 Node/TypeScript 服务、PostgreSQL 容器、持久化卷及数据库用户；不复用 Cloud Whale 的账号或数据。经过现有 Nginx HTTPS 入口，避开当前代理占用的 443。
- 首次开启时选择同步类别。可同步设置（主题/语言等可移植字段）、网页入口、固定项、别名、短语、AI 动作和非秘密模型配置、便笺、稿纸。工作区和快捷键按设备校验/映射；远端到达不执行程序、不自动授予权限。
- 剪贴板收藏、图片和完整历史分别默认关闭。API Key、账号 token、Cookie 不同步。文件历史不上传原文件或把其他机器绝对路径当可用文件。
- 插件清单用于提示与选择安装；任意私有插件数据库不自动上传。现有便笺/AI 动作使用明确适配器。
- 本地先保存，持久化 outbox，增量拉取/推送。实体有稳定 ID、schema、版本、删除标记和用户作用域。服务端单调序号、版本比较与幂等 mutation ID，不以客户端时间判定覆盖。
- 同条目并发修改保留冲突副本/候选值，由用户选择；离线删除不能被旧设备复活。拉取进度和本地应用原子更新；过期游标要求快照重建，不跳过删除。停止同步不删除本地内容；切换账号不能复用旧 outbox 或自动上传旧账号内容。
- 初期每账号 100 MiB 配额，单条/单图限额与现有读取限制相符；服务总体容量、请求大小、速率和磁盘余量有明确边界。超限不损坏已有本地内容。
- HTTPS、服务端加密保存同步正文；不宣称端到端加密。支持每日备份、部署时离机备份与真实恢复演练。日志不记录正文或凭据。GitHub OAuth 凭据通过安全配置提供。

## AI 模型

- 宿主设置管理供应商、模型、默认模型、手动模型 ID、协议、上下文/输出限制、图片输入和适用的推理选项。
- 协议：Chat Completions、Responses、Anthropic Messages；独立请求和 SSE 解析，统一文本/工具调用/用量/结束/失败事件。中断、拒绝、截断不会冒充正常完成。
- 旧 `nexlet.ai.configure/models/chat/onChunk` 合同保留；共享模型以新增 API 接入，不能把新事件格式强塞给旧插件。显式迁移插件已有配置，不静默共享私有密钥。
- AI 动作和翻译共用选定模型。密钥只供宿主请求使用，修改服务地址不携带旧密钥。输出/工具调用不自动执行。
- 单次请求由用户操作触发，具有取消、超时、消息和输出大小限制。Responses 默认不保存服务端会话。

## OCR/翻译提供商

- 定义与 AI 配置不同的能力注册表：OCR、translation；提供商有稳定 ID、所属插件、显示名称、本地/联网属性、方法和输入输出 schema。
- 内置消费方及获授权插件可列出/调用默认或指定提供商；图片通过有大小边界的数据或资源授权传递，不能跨插件偷读资源。
- 先接入现有离线 OCR 和翻译。OCR 输出正文，可带文字块坐标/置信度；翻译输出译文和检测语言。
- 注册、停用、卸载、运行中更新、取消、超时、错误均有明确生命周期。不在失败后自动跨本地/云端边界降级。
- 剪贴板图片索引取消固定插件依赖，截图 OCR/翻译复用注册表。消费端错误提示可定位缺失提供商。

## 截图

- 保持当前框选入口，完成选区后可编辑：矩形、椭圆、箭头、画笔、文字、高亮、马赛克、实色遮挡。
- 标注支持选择/移动/删除、撤销重做；导出最终 PNG 时把标注和遮挡烘焙进位图。
- 输出沿用复制/保存/贴图/继续处理；增加 OCR、翻译，复用提供商和现有结果交接。
- 长截图采用用户手动滚动后采集片段，匹配重叠区域；失败可调整重叠或删除片段，不注入滚轮。对最大像素/边长/片段数设限。
- 支持多屏 DIP/像素转换，处理取消、权限拒绝、无画面、内存上限和晚到任务结果。平台实际能力不足时明确提示。

## 市场与插件更新

- 沿用卡片列表；分类、名称/更新时间排序；详情按需展开说明、预览、源码、要求、版本日志。
- 下载逐项进度、取消、重试、更新列表；权限在安装前可见，更新新增权限时必须确认后激活。

- 不生成没有真实数据的排行榜。不自动发布新版索引或插件包到 GitHub。

## 三个首批插件

- PDF：合并、拆分、提取、重排、旋转、图片转 PDF、PDF 转图片；不承诺 PDF→Office 高保真转换。
- 图片批处理：压缩、转换、缩放、水印、拼图；新文件输出、逐项结果、取消。复用 Sharp/宿主能力和沙箱。
- 批量重命名：替换、编号、前后缀、预览、冲突检测、日志、可用时撤销。执行前重验文件身份，部分失败不伪装整批成功，撤销遇到外部修改不覆盖。
- 脚本任务管理仅列为后续建议，不在本轮新增。
- 三语入口和必要界面文案，支持结果交接。复用库时保存许可，不直接复制许可不明的竞争项目代码。

## 压力测试结论

1. 账号同步是新的宿主能力，不等同于已有插件 `services` 适配接口；服务端不能信任客户端 userId。
2. 导出文件是类别快照，不可直接作为连续双向同步协议；需实体版本、outbox、幂等和删除状态。
3. 设备路径/快捷键/插件权限属于执行环境，不能通过同步直接启用。
4. 旧 AI 事件与三协议新事件合同不同，应新增共享调用路径并保留旧路径。
5. 提供商默认切换不意味着允许把本地数据发送到云；联网属性和用户选择必须保留。
6. 正在运行的插件不能被后台新版本替换，新增权限不能由自动更新绕过。
7. 同步错误、取消和账号切换的晚到结果必须丢弃；撤销设备同时撤销服务端会话。
8. 长截图和批处理测试使用合成数据及受控 fixture，不占用真实桌面。

## 验收与回滚

每阶段完成有意义的单元/集成检查、三语校验、类型/lint/格式检查和构建。公共协议、真实 PostgreSQL、备份恢复、授权隔离用集成测试验证。真实 GitHub 登录与平台屏幕权限若不能完成，明确记录未验证部分，不能用 fixture 宣称通过。

新功能默认可关闭；保留本地原数据和旧 SDK。数据库迁移使用增加表/字段方式；回滚先停止同步再恢复服务版本和经验证备份，不覆盖并发数据。服务部署使用独立容器与 Nginx 路径，保留前一版配置与镜像。客户端不自动发布。
