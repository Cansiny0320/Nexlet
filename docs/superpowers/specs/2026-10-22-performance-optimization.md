# 全部性能热点优化

用户于 2026-10-22 批准本设计，并明确插件改为“先打开、后台下载、下次启用新版”。覆盖七项热点；不提交、推送或发布。

## 目标与行为合同

1. 图片处理：按需建立可信、无远程内容的专用 renderer，继续使用 nativeImage 完成原有 PNG 编码、hash、缩略图，异步落盘，空闲 30 秒回收。保留颜色、透明度、尺寸和去重规则；测首次启动、热处理、主线程阻塞及额外内存。
2. 剪贴板全文搜索：剪贴板数据读写通过 Worker 串行执行，主进程保留 settings/pads。合并连续查询并拒绝过期结果；保留 Unicode 小写子串、排序、收藏、board 范围、ID 和分页 revision 合同。不将 Worker 故障回退为主线程重活。
3. 剪贴板摘要：增加可重建派生表，写入时生成检索文本、600 UTF-16 单元摘要及 Unicode 字符数。旧 clips 表保持兼容；旧历史后台分批回填、当前页面优先，未回填记录仍可检索。缓存失效需兼容旧版程序写入。额外检索文本占用磁盘，删除历史时同步回收。
4. 插件更新：立即打开已安装版本，后台检查并下载暂存，下一次无运行 session 时原子应用。检查成功节流 30 分钟，失败短退避；保留本地/开发来源、compatibility、feature、input、配置与密钥。运行中不重启，关闭不复活；停用、卸载、退出取消下载及过时任务。暂存失败可继续旧版。
5. 状态刷新：更新进度单独通知，搜索相关命令未变化时保留稳定引用；快捷键和 startup 只在相关输入变化时刷新，实际数据变化仍使搜索失效。
6. Linux 文件搜索：仅用户指定目录，按需会话缓存目录项，每次搜索验证目录 identity/mtime/ctime，变化时重读。容量有界，不把部分扫描当完整；继续跳过隐藏项和符号链接，保持 200 结果、100000 visited、5 秒、深度 64 及取消规则。新增目录、祖先移除、权限变化和替换不产生永久陈旧结果。
7. 后台轮询：panel busy 不变时不读配置；macOS 事件泵以 CFRunLoop 原生有界等待替代 8 ms 空闲 JS 定时器，idle 最长 50 ms，手势期间精细检查，真实事件触发立即返回。保留 Windows 原生等待实现。

## 压力测试与约束

已使用 brainstorming 和 grill-with-docs 检查数据兼容、查询期间变更、多窗口分页/权限、Worker 退出、图像编码一致性、插件并发打开/关闭/卸载、缓存漏事件、鼠标短按/长按/拖动及退出释放。实现与测试覆盖上述边界。nativeImage 官方仅支持 Main/Renderer，故不放入 Node Worker 或 utilityProcess。

不引入新的全文搜索算法、长期全盘索引或数据库整体替换。保留原始 clips 数据与现有公开 API。增加的内部异步边界必须逐个核对 caller 和退出顺序。

## 验收与回滚

同一 Apple M3 Pro / macOS arm64 / Node 24.19.0 / Electron 44 环境，固定合成文本、图片、文件树及模拟网络，隔离 userData，不读写真实剪贴板。基线为开始实施前当前源码快照，记录 HEAD、文件 hash 与已有 diff。

普通短文本、500×32 KiB、5000×32 KiB 搜索；40×1 MiB 摘要；1080p/4K/24MP 图片；800 ms 与超时网络插件打开；重复状态通知；文件树首次/重复/变化查询。尽量交替执行五组，报告 p50/p95、事件循环延迟、CPU/RSS 和 I/O 次数。微基准和端到端、macOS 实机和平台模拟分别报告，不外推跨平台收益。

完成单测、非修复 check、build 和相关 Electron 集成测试；只修复本次导致的问题。回滚源码即可恢复旧行为，旧 clips 原始数据可供旧版读取；派生表可删除重建，未应用的插件暂存包可清理。无远端或生产操作。
