# 文件搜索中的目录浏览与信息预览

已批准：双击文件夹在 Nexlet 内列出直接子项；单击文件或文件夹在右侧显示名称、完整路径、类型、创建时间和修改时间，文件另显示大小。双击文件及 Enter 使用系统默认应用打开文件；文件夹 Enter 与双击一致。保留资源管理器打开和复制路径操作。

采用左侧列表、右侧信息面板。目录模式有面包屑、上一级和返回搜索；返回保留原搜索词和选择。目录内输入只按名称筛选当前目录，返回恢复全局搜索。按文件类型显示目录、文档、图片、音频、视频、压缩包、代码、程序及未知类型图标。

目录内容直接读取文件系统，分批加载大目录；不递归扫描、不依赖搜索索引更新。错误明确显示不可访问、已删除等情况。详情请求和目录切换的旧响应不得覆盖新选择。空目录、无匹配项和加载状态分别呈现。

主进程只接受当前窗口已取得的搜索结果、目录子项与可导航父目录；新搜索及窗口销毁撤销旧授权。不允许渲染器传任意路径读取。窗口分离/恢复时重放原搜索与导航路径，重新取得授权；无法恢复时显示错误并允许返回搜索。

不添加内容预览、文件修改或递归目录大小。无需新增依赖。保留其他正在进行的资源和页面改动。
