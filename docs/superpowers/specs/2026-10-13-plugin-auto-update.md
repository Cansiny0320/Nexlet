# 插件打开前自动更新

用户已确认以下规则（2026-10-13）：市场安装的插件每次重新打开时检查更新，有兼容新版先更新再打开；不弹确认；索引检查最多 2 秒，包下载最多 10 秒，失败继续打开旧版；保留配置、密钥和本次输入；已有会话不重启；开发目录、本地导入不自动覆盖；重复点击合并更新。

## 现有约束与方案

- `Marketplace.list()` 默认返回持久缓存。自动检查必须重新获取索引，沿用索引、平台、宿主版本、包 ID/版本和 ZIP 校验。
- `PluginRuntime.launch()` 已串行化启动，已有会话复用。仅在创建会话前增加准备步骤；同一插件的后续打开复用已创建会话，不重复下载。
- `Marketplace` 只准备、校验新包，`PluginManager` 负责替换。安装前再次确认记录仍是同一个已启用市场版本，没有运行会话，启动请求尚未取消。
- 自动替换不结束正在运行的会话；仍保留原子写入新目录、成功后变更安装记录、最后清理旧目录的顺序。配置和密钥存储不变。
- 更新包移除了本次要打开的 feature 时保留旧版；本地或开发插件、无新版、不兼容、下载/校验失败均继续原有启动流程。
- 运行时取消信号贯穿检查和下载。退出、停用、卸载、关闭宿主后不能晚到安装或打开插件。

## 验收

真实 Electron 环境验证新版被打开、旧缓存不阻止更新、输入与独立数据保留、已有会话和分离窗口不重启、重复点击只更新一次。覆盖断网、超时、坏包、本地/开发安装、feature 不兼容和取消期间不复活。

## 边界

本次只实现和验证宿主行为，不修改插件 API 或新增后台定时更新。本次确认不包含新的 commit、push 或发布。
