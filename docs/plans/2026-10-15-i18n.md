# 实施计划

依据 ../specs/2026-10-15-i18n.md，README 默认中文。

1. 桌面基础：新增 src/shared/i18n.ts 与 locales；修改 shared/types.ts、main/index.ts、renderer/main.tsx、Settings.tsx 和 preload。统一 locale 解析/持久化/广播，资源离线加载；先用 tests/i18n.test.ts 验证映射、回退、插值、兼容旧设置。
2. 桌面内容：迁移 renderer、main 和 shared 的产品文案及格式化；命令保持稳定 ID，双语搜索；主进程生成的目录/托盘/标题动态刷新，旧状态不重挂载。tests/i18n.spec.ts 验证切换、多窗口、输入保留、重启；运行 npm run typecheck、npm test、npm run build、相关 Playwright。
3. 插件：扩展 shared/plugin-api.ts、plugin-validation.ts、marketplace.ts、preload/plugin.ts、plugin-runtime.ts；同步 ../Nexlet-plugins/sdk，增加可选翻译元数据及语言事件。自有三插件迁移文案，Ctool adapter 跟随语言，繁体回退简体。运行插件 typecheck/test/build 和相关真实宿主测试。
4. 官网：website/src/lib/i18n、语言 Provider、本地化路由/页面/共享组件/seo，public/sitemap.xml；不共享可变服务端实例。运行 pnpm verify、pnpm format:check、pnpm test:browser，增加三语 SSR/切换测试。
5. 文档/图片：主仓、官网、插件仓/SDK/模板 README 与公开 SDK/Linux 文档的 en/zh-Hant 对等版本及链接；隔离用户数据抓取三语主要产品截图，更新官网宣传资源。校验文档链接、词条完整性和布局。
6. 回读两仓 diff/status，记录验证证据与平台限制。

命令副作用：依赖安装更新锁文件和 node_modules；build 写 dist；网站 build 生成路由树和 .wrangler；E2E 使用临时用户数据并写测试结果；format 仅在本次网站改动范围显式运行。测试不发布或下载正式安装包，不改用户日常数据。

风险：硬编码遗漏、模块初始化时缓存翻译、跨窗口事件、SSR 串语言、英文布局溢出、SDK 双仓类型漂移。通过资源审计与针对性用例控制。回滚仅撤销本次变更；新增设置字段和可选插件元数据向后兼容。无破坏性数据迁移。
