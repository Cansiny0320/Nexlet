# 共享能力、截圖和賬號同步

這些改動面向 Nexlet 0.2.47；本地構建不等於已經發布的客戶端版本。

## 共享 AI 與提供商

在設定的「AI 模型」中新增服務地址、協議、模型 ID 和預設模型。支援 Chat Completions、Responses、Anthropic Messages。金鑰只由主程序使用，系統加密不可用時只保留在記憶體。更換地址或協議會清除舊金鑰。模型列表可手動填寫；測試操作使用已儲存配置。圖片／工具能力需顯式開啟，工具呼叫只返回資料，不執行工具。

舊版 `nexlet.ai.configure/models/chat/onChunk` 保留原合同。AI 動作可選擇共享模型或舊私有配置；「遷移舊版 AI 動作模型」只匯入地址和模型，不復制金鑰。翻譯外掛支援共享模型。

「OCR 與翻譯」分別選擇預設提供商。OCR 外掛提供本地 Paddle OCR；翻譯外掛提供 Google 和共享 AI 翻譯。提供商缺失、停用、升級或失敗時會報錯，不自動跨本地／雲端邊界降級。帶 schema 的提供商可展開配置並儲存 JSON。

## 截圖與市場

框選後進入編輯，支援矩形、橢圓、箭頭、畫筆、文字、醒目提示、馬賽克、模糊和實色遮擋。支援選擇／移動／刪除標註與撤銷／重做。匯出 PNG 會將標註烘焙到畫素。

長截圖採用手動滾動：採集時視窗隱藏 3 秒，由使用者滾動原頁面。重疊不確定時可調整高度或刪除片段。最多 30 段、3600 萬畫素、32768 畫素高，輸出不超過 20 MiB。Linux 暫不支援重複採集，仍可使用普通截圖。截圖和固定圖片視窗可呼叫共享 OCR／翻譯，並複製或繼續處理結果。

市場支援列表／卡片、分類、名稱／更新時間排序和展開詳情。下載任務可取消、重試；下載完成後再次確認安裝。新增許可權或本地提供商變成雲端服務時必須重新確認，後臺更新不會繞過這一步。

## 賬號與同步

GitHub 登入在系統瀏覽器中確認裝置程式碼，客戶端通過 Better Auth Device Authorization 獲取 Nexlet 會話。GitHub 憑據和 Nexlet 會話不交給渲染器或外掛。賬號公開註冊，每個賬號有 100 MiB 同步空間。

首次登入不會自動上傳。逐項選擇設定、指令、固定項、網頁入口／書籤、短語、AI 動作、共享模型、便箋、稿紙和外掛清單。剪貼簿收藏文本、圖片和歷史分別預設關閉。API Key、賬號憑據和外掛私有資料庫不上傳；檔案歷史只同步檔名，不能在另一臺裝置開啟原檔案。

路徑和快捷鍵以待確認對映呈現，必須選擇本機存在的路徑並通過快捷鍵檢查後應用。外掛清單僅提供下載入口，下載後仍需安裝確認。同步正文在服務端加密儲存，並非端到端加密。

本地儲存後進入持久化佇列；重啟／斷網後可重試。服務端以版本號比較更新，重複 mutation 不重複執行。併發修改保留本機和雲端版本，由使用者選擇；刪除標記防止離線裝置自動復活資料。賬號切換清空舊佇列，新的賬號預設不選擇同步類別。可檢視／撤銷裝置、退出登入或刪除雲端賬號。賬號刪除要求最近 10 分鐘內登入；本機內容保留，歷史服務備份最多保留 7 天。

## 實用外掛

另一個倉庫 `Nexlet-plugins` 提供 PDF 工具、圖片批處理和批次重新命名。處理範圍、大小限制、第三方許可證和取消／恢復行為見各外掛 README。本地安裝包不表示已上傳到公開外掛市場。

## 驗證邊界

純後臺測試覆蓋三種 AI 流、提供商生命週期、截圖實際畫素、安裝任務、同步佇列／事務、真實 PostgreSQL、備份恢復，以及 PDF／圖片／重新命名結果。桌面許可權、多屏實際採集、手動長截圖和最終視覺互動需要在允許視窗測試時另行驗收；不能把合成圖片檢查視為這些平臺流程已通過。
