# Nexlet i18n 維護說明

介面支援簡體中文（`zh-CN`）、繁體中文（`zh-Hant`）與 English（`en`）。本說明對應開發原始碼，釋出狀態以正式 Release 和部署版本為準。

## 桌面

`settings.language` 為 `system | zh-CN | zh-Hant | en`，舊配置預設 `system`。系統 `zh-TW/zh-HK/zh-MO/zh-Hant` 解析為繁體，其他 `zh` 為簡體，其餘語言為英文。顯式設定優先。

主程序 `src/shared/i18n.ts` 與各 renderer 持有自己的 i18next 例項。宿主儲存偏好後廣播有效語言，重新整理托盤、工具標題和命令；renderer 更新文案而不重掛載工具。日期、數字按介面語言展示，運算輸入、協議值、命令 ID 與使用者內容不翻譯。

簡體文案是穩定詞條鍵，英文和繁體資源在 `src/shared/locales/`。缺詞回退源文案。新增文案應以完整句子為鍵，透過 `{{name}}` 插值；不要拼接翻譯片段，不要翻譯使用者輸入、路徑或錯誤碼。模組頂層不要快取 `t()` 的結果，切換時應重新讀取。數值展示使用 locale 格式化，涉及數量的英文句子應檢查單複數。

## 外掛

```js
let changed = false;
const off = nexlet.i18n.onChange(locale => {
  changed = true;
  renderLabels(locale); // 只更新产品文案，保留用户输入
});
const initial = await nexlet.i18n.getLocale();
if (!changed) renderLabels(initial);
// 页面不再需要订阅时 off()
```

支援舊版宿主時先檢測 `nexlet.i18n`，預設可使用瀏覽器語言。`system.info().locale` 的系統資訊含義不變；語言 API 無需許可權。Manifest、feature、市場條目均可選提供以下顯示欄位，舊 manifest 不需要遷移：

```json
{
  "name": "便笺",
  "locales": {
    "en": { "name": "Notes", "description": "Keep a local note" },
    "zh-Hant": { "name": "便箋", "description": "儲存本機便箋" }
  }
}
```

`name` 最多 50 字元，`description` 最多 500，`category` 最多 30；欄位非空。語言僅接受三個支援值。選中語言缺欄位時先用 `zh-CN` 對應欄位，再回退原欄位。語言名稱加入搜尋別名，不改變 plugin ID、feature code、版本或儲存鍵。外掛自身維護介面資源，宿主不會自動翻譯第三方頁面。

便箋、字數統計和翻譯使用 `Nexlet-plugins/shared` 的共用資源，透過 `node scripts/sync-i18n.mjs` 同步本地副本，保持直接載入開發目錄可用。Ctool 只使用上游已有英文、簡體資源；繁體回退簡體，適配發生在構建層，不改 vendor 歸檔。

## 官網和文件

官網簡體路徑不變；英文和繁體分別使用 `/en/`、`/zh-Hant/` 字首。URL 決定 SSR/首屏語言，禁止共用可變的服務端全域性語言例項。新增頁面要同時補 canonical、hreflang、sitemap、元資訊和語言導航。

`README.md` 預設簡體，`.en.md` 和 `.zh-Hant.md` 是對等文件；三份互鏈。公開 SDK、Linux、官網、外掛及模板說明同步維護；歷史釋出和驗收記錄保持原文。翻譯程式碼註釋或示例文案時，不改變 API 標識、字串協議、路徑和命令。對應語言的產品截圖放在 `docs/screenshots/<locale>/`，營銷示意與真實資料截圖要區分。

## 驗證

主倉執行 `npm run typecheck`、`npm test`、`npm run build`，再執行 `npm exec -- playwright test tests/i18n.spec.ts`。外掛倉執行 `npm run typecheck`、`npm test`、構建與真實宿主驗證。官網執行 `pnpm verify`、`pnpm format:check`、`pnpm test:browser`。

語言迴歸應覆蓋：系統對映、缺詞與插值、已有配置、持久化、多視窗同步、輸入保留、三語搜尋、舊外掛、九頁 SSR/SEO 與窄屏。不要將 macOS 本地驗收描述為 Windows/Linux 原生驗收或線上釋出。
