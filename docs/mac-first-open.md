## Mac 首次打开 / First launch on macOS

当前 macOS 版本尚未经过 Apple 公证。确认安装包来自 [Nexlet 官方 GitHub Releases](https://github.com/Cansiny0320/Nexlet/releases) 后，请按以下步骤打开：

1. 将 DMG 中的 Nexlet 拖入「应用程序」文件夹。
2. 从「应用程序」打开 Nexlet；如出现「Apple 无法验证 Nexlet」提示，点击「完成」。
3. 打开「系统设置 → 隐私与安全性」，向下找到 Nexlet 的拦截提示，点击「仍要打开」。
4. 按提示验证密码或 Touch ID，再确认「打开」。

没有看到「仍要打开」？请重新尝试打开 Nexlet，再回到该设置页面。完成后，系统会保存该应用的例外。

The current macOS build is not notarized by Apple. Only proceed after confirming that your download comes from the official Nexlet GitHub Releases:

1. Drag Nexlet from the DMG into **Applications**.
2. Open Nexlet from **Applications**. If macOS says Apple could not verify Nexlet, click **Done**.
3. Go to **System Settings → Privacy & Security**, scroll down to the notice about Nexlet and click **Open Anyway**.
4. Authenticate with your password or Touch ID when prompted, then confirm **Open**.

No **Open Anyway** button? Try opening Nexlet again, then return to this settings page. macOS will save an exception for the app once you confirm.
