# 共享能力、截图和账号同步

这些改动面向 Nexlet 0.2.47；本地构建不等于已经发布的客户端版本。

## 共享 AI 与提供商

在设置的「AI 模型」中添加服务地址、协议、模型 ID 和默认模型。支持 Chat Completions、Responses、Anthropic Messages。密钥只由主进程使用，系统加密不可用时只保留在内存。更换地址或协议会清除旧密钥。模型列表可手动填写；测试操作使用已保存配置。图片／工具能力需显式开启，工具调用只返回数据，不执行工具。

旧版 `nexlet.ai.configure/models/chat/onChunk` 保留原合同。AI 动作可选择共享模型或旧私有配置；「迁移旧版 AI 动作模型」只导入地址和模型，不复制密钥。翻译插件支持共享模型。

「OCR 与翻译」分别选择默认提供商。OCR 插件提供本地 Paddle OCR；翻译插件提供 Google 和共享 AI 翻译。提供商缺失、停用、升级或失败时会报错，不自动跨本地／云端边界降级。带 schema 的提供商可展开配置并保存 JSON。

## 截图与市场

框选后进入编辑，支持矩形、椭圆、箭头、画笔、文字、高亮、马赛克、模糊和实色遮挡。支持选择／移动／删除标注与撤销／重做。导出 PNG 会将标注烘焙到像素。

长截图采用手动滚动：采集时窗口隐藏 3 秒，由用户滚动原页面。重叠不确定时可调整高度或删除片段。最多 30 段、3600 万像素、32768 像素高，输出不超过 20 MiB。Linux 暂不支持重复采集，仍可使用普通截图。截图和固定图片窗口可调用共享 OCR／翻译，并复制或继续处理结果。

市场支持列表／卡片、分类、名称／更新时间排序和展开详情。下载任务可取消、重试；下载完成后再次确认安装。新增权限或本地提供商变成云端服务时必须重新确认，后台更新不会绕过这一步。

## 账号与同步

GitHub 登录在系统浏览器中确认设备代码，客户端通过 Better Auth Device Authorization 获取 Nexlet 会话。GitHub 凭据和 Nexlet 会话不交给渲染器或插件。账号公开注册，每个账号有 100 MiB 同步空间。

首次登录不会自动上传。逐项选择设置、指令、固定项、网页入口／书签、短语、AI 动作、共享模型、便笺、稿纸和插件清单。剪贴板收藏文本、图片和历史分别默认关闭。API Key、账号凭据和插件私有数据库不上传；文件历史只同步文件名，不能在另一台设备打开原文件。

路径和快捷键以待确认映射呈现，必须选择本机存在的路径并通过快捷键检查后应用。插件清单仅提供下载入口，下载后仍需安装确认。同步正文在服务端加密存储，并非端到端加密。

本地保存后进入持久化队列；重启／断网后可重试。服务端以版本号比较更新，重复 mutation 不重复执行。并发修改保留本机和云端版本，由用户选择；删除标记防止离线设备自动复活数据。账号切换清空旧队列，新的账号默认不选择同步类别。可查看／撤销设备、退出登录或删除云端账号。账号删除要求最近 10 分钟内登录；本机内容保留，历史服务备份最多保留 7 天。

## 实用插件

另一个仓库 `Nexlet-plugins` 提供 PDF 工具、图片批处理和批量重命名。处理范围、大小限制、第三方许可证和取消／恢复行为见各插件 README。本地安装包不表示已上传到公开插件市场。

## 验证边界

纯后台测试覆盖三种 AI 流、提供商生命周期、截图实际像素、安装任务、同步队列／事务、真实 PostgreSQL、备份恢复，以及 PDF／图片／重命名结果。桌面权限、多屏实际采集、手动长截图和最终视觉交互需要在允许窗口测试时另行验收；不能把合成图片检查视为这些平台流程已通过。
