# 效率功能使用說明

這些功能從 Nexlet v0.2.42 開始提供。請先更新主程式，再在外掛市集更新對應外掛。

1. **快捷短語**：建立名稱、分組及內文，支援 `{{date}}`、`{{date:YYYY-MM-DD HH:mm:ss}}`、`{{clipboard}}`、`{{input:姓名}}`。以 `\{{` 輸出字面量 `{{`。填入變數並預覽後，再複製、貼回或繼續處理。已儲存的短語會成為可固定、設定別名與快速鍵的指令。
2. **繼續處理**：將內建工具及適配外掛的結果帶回啟動器，再選下一個工具。文字、HTML、圖片及檔案直接交接；重新開啟來源工具可恢復狀態。
3. **設定檔**：在設定匯出可編輯的 `.nexlet.jsonc`。匯入前預覽差異、勾選類別，再套用；支援復原上次匯入。外掛清單僅供核對。API Key、剪貼簿內文、圖片、草稿及外掛私人資料庫不會匯出；路徑及 Prompt 等設定本身仍可能包含私人資訊。
4. **工作區**：依序加入應用程式、目錄、編輯器、終端機與網頁。程式與參數分開設定。支援執行全部、單項及僅重試失敗項目；取消只停止後續啟動，不關閉已開啟的程式。
5. **圖片文字搜尋**：從外掛市集安裝離線 OCR 1.1.0 或更新版本後，可辨識歷史圖片或新增本機圖片。設定可啟用收藏圖片自動辨識。任務逐一執行、可取消；清除辨識文字會保留原圖。
6. **AI 動作**：配套外掛提供解釋錯誤、潤飾、提取待辦及產生提交說明。先填入模型、服務位址與 API Key，可修改 Prompt 或新增動作。點選執行後才傳送內容，支援串流、取消、複製、貼回及繼續處理。金鑰由宿主 secrets 管理，不進入設定匯出；結果不會自動執行。
7. **工具狀態**：本次執行期間切換工具會保留輸入、結果、選項與捲動位置。設定可啟用跨重啟恢復及清除草稿。獨立視窗保持隔離，跨重啟只恢復主視窗草稿；普通草稿沒有額外加密。
8. **富文字歷史**：同時保留 HTML 與純文字；複製或貼回可保留格式，也可選純文字動作。歷史表格可繼續交給文字表格轉圖片。歷史預覽不執行 HTML。
9. **動作選單**：在啟動器、剪貼簿、檔案及工具結果按 `Cmd/Ctrl+K` 或開啟右鍵選單。方向鍵選擇、`Enter` 執行、`Escape` 返回並恢復焦點。
10. **搜尋**：支援輕量英文拼字容錯、文字與拼音醒目標示、本機關鍵字偏好；精確匹配優先。只學習一般指令名稱查詢，不學習帶入內文。設定可清除學習紀錄。
11. **記錄控制**：暫停 15 分鐘、排除前景應用程式，或預覽並清理時間範圍；預設保留收藏。Wayland 等無法可靠取得來源的環境不能保證按應用程式排除。
12. **檔案預覽**：選取檔案後預覽圖片或 UTF-8 文字，方向鍵切換。文字上限 256 KiB，圖片上限 20 MiB / 3600 萬像素；不執行腳本、HTML 或 Markdown。
