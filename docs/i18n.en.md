# Maintaining Nexlet i18n

Supported languages are Simplified Chinese (`zh-CN`), Traditional Chinese (`zh-Hant`), and English (`en`). This guide describes development source; releases and deployments determine availability.

## Desktop

`settings.language` is `system | zh-CN | zh-Hant | en`; old configurations default to `system`. System `zh-TW/zh-HK/zh-MO/zh-Hant` maps to Traditional Chinese, other `zh` to Simplified Chinese, and everything else to English. Explicit preferences win.

The main process and renderers have separate i18next instances through `src/shared/i18n.ts`. Saving broadcasts the effective locale and refreshes tray, tool titles, and commands. Renderers update labels without remounting tools. Date/number display follows UI locale; calculation input, protocol values, command IDs, and user content remain unchanged.

Simplified Chinese source messages are stable keys; English/Traditional resources live in `src/shared/locales/`. Missing messages fall back to the source. Add complete sentences and `{{name}}` interpolation, not concatenated fragments. Never translate user input, paths, or error codes. Do not cache `t()` results at module scope; read them again on language changes. Format displayed numbers with the locale and check English singular/plural forms.

## Plugins

```js
let changed = false;
const off = nexlet.i18n.onChange(locale => {
  changed = true;
  renderLabels(locale); // Update product labels, preserve user input
});
const initial = await nexlet.i18n.getLocale();
if (!changed) renderLabels(initial);
// Call off() when the subscription is no longer needed.
```

Feature-detect `nexlet.i18n` for older hosts and optionally fall back to browser language. `system.info().locale` remains OS information. The new API needs no permission. Manifest, feature, and marketplace metadata may include optional display fields; legacy manifests need no migration:

```json
{
  "name": "便笺",
  "locales": {
    "en": { "name": "Notes", "description": "Keep a local note" },
    "zh-Hant": { "name": "便箋", "description": "儲存本機便箋" }
  }
}
```

Limits: name 50, description 500, category 30 characters; fields must be nonempty. Only the three supported locale keys are accepted. Missing selected-language fields fall back through `zh-CN` to original fields. Localized names become search aliases without changing IDs, feature codes, versions, or storage keys. Plugins own their UI resources; the host does not translate arbitrary third-party pages.

Notes, Word count, and Translate share `Nexlet-plugins/shared` resources. Run `node scripts/sync-i18n.mjs` to update local copies, keeping raw development directories usable. Ctool uses existing upstream English/Simplified resources; Traditional Chinese falls back to Simplified. Build-time adapters leave the vendor archive untouched.

## Website and documentation

Simplified Chinese paths remain; English and Traditional use `/en/` and `/zh-Hant/`. URL determines SSR and initial hydration. Never share mutable server language globally. New pages need canonical, hreflang, sitemap, metadata, and language navigation.

`README.md` stays Simplified Chinese; `.en.md` and `.zh-Hant.md` are peer documents with reciprocal links. Keep public SDK, Linux, website, plugin, and template guides aligned; historical release/validation records remain in their original language. Preserve API identifiers, protocol strings, paths, and commands when translating comments or examples. Put localized screenshots in `docs/screenshots/<locale>/` and distinguish illustrations from real data.

## Verification

Host: `npm run typecheck`, `npm test`, `npm run build`, then `npm exec -- playwright test tests/i18n.spec.ts`. Plugins: typecheck, tests, build, and real-host tests. Website: `pnpm verify`, `pnpm format:check`, `pnpm test:browser`.

Cover system mapping, fallback/interpolation, old settings, persistence, multiple windows, preserved input, multilingual search, legacy plugins, nine SSR/SEO routes, and narrow layouts. Local macOS validation does not establish native Windows/Linux behavior or production deployment.
