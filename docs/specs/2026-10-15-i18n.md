# Nexlet 三语言支持

2026-10-15：用户批准实施；README 默认中文。语言为 zh-CN、zh-Hant、en。

桌面默认跟随系统，可显式选择语言并持久化。主窗口、独立工具、超级面板、托盘和新弹窗同步，不重载或丢失用户输入。翻译界面、主进程提示、无障碍文本和展示格式，保留命令 ID、用户数据、运算/协议格式及中英文和拼音搜索。

采用 i18next / react-i18next，资源随包离线可用。官网独立词条和请求实例；中文沿用原路径，英文 /en/，繁体 /zh-Hant/。URL 决定 SSR/首屏语言；切换保留页面，翻译 SEO、hreflang、sitemap 和 404。

README.md 保持简体中文，README.en.md / README.zh-Hant.md 对等版本互链。公开 SDK、模板、Linux 使用文档同步；历史发布和验收资料不翻译。主要产品截图和官网宣传图提供对应语言内容。

插件增加应用语言读取/变化通知，不改变 system.info().locale 含义；manifest 和市场索引增加可选本地化名称、描述、功能标签，旧插件兼容。便笺、翻译和字数统计支持三语。Ctool 复用上游中英文，繁体回退简体，通过适配层跟随应用语言，不重写上游工具。

验收：语言解析、缺词/插值、设置迁移/持久化、多窗口同步且输入保留、双语搜索、SDK/旧插件兼容；官网三语 SSR、SEO、路由、链接、窄屏；类型检查、构建和相关回归。仅本地实现验证，不 commit/push/部署/安装。
