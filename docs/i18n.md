# Nexlet i18n 维护说明

界面支持简体中文（`zh-CN`）、繁体中文（`zh-Hant`）与 English（`en`）。本说明对应开发源码，发布状态以正式 Release 和部署版本为准。

## 桌面

`settings.language` 为 `system | zh-CN | zh-Hant | en`，旧配置缺省 `system`。系统 `zh-TW/zh-HK/zh-MO/zh-Hant` 解析为繁体，其他 `zh` 为简体，其余语言为英文。显式设置优先。

主进程 `src/shared/i18n.ts` 与各 renderer 持有自己的 i18next 实例。宿主保存偏好后广播有效语言，刷新托盘、工具标题和命令；renderer 更新文案而不重挂载工具。日期、数字按界面语言展示，运算输入、协议值、命令 ID 与用户内容不翻译。

简体文案是稳定词条键，英文和繁体资源在 `src/shared/locales/`。缺词回退源文案。新增文案应以完整句子为键，通过 `{{name}}` 插值；不要拼接翻译片段，不要翻译用户输入、路径或错误码。模块顶层不要缓存 `t()` 的结果，切换时应重新读取。数值展示使用 locale 格式化，涉及数量的英文句子应检查单复数。

## 插件

```js
let changed = false;
const off = nexlet.i18n.onChange(locale => {
  changed = true;
  renderLabels(locale); // 只更新产品文案，保留用户输入
});
const initial = await nexlet.i18n.getLocale();
if (!changed) renderLabels(initial);
// 页面不再需要订阅时 off()
```

支持旧版宿主时先检测 `nexlet.i18n`，缺省可使用浏览器语言。`system.info().locale` 的系统信息含义不变；语言 API 无需权限。Manifest、feature、市场条目均可选提供以下显示字段，旧 manifest 不需要迁移：

```json
{
  "name": "便笺",
  "locales": {
    "en": { "name": "Notes", "description": "Keep a local note" },
    "zh-Hant": { "name": "便箋", "description": "儲存本機便箋" }
  }
}
```

`name` 最多 50 字符，`description` 最多 500，`category` 最多 30；字段非空。语言仅接受三个支持值。选中语言缺字段时先用 `zh-CN` 对应字段，再回退原字段。语言名称加入搜索别名，不改变 plugin ID、feature code、版本或存储键。插件自身维护界面资源，宿主不会自动翻译第三方页面。

便笺、字数统计和翻译使用 `Nexlet-plugins/shared` 的共用资源，通过 `node scripts/sync-i18n.mjs` 同步本地副本，保持直接加载开发目录可用。Ctool 只使用上游已有英文、简体资源；繁体回退简体，适配发生在构建层，不改 vendor 归档。

## 官网和文档

官网简体路径不变；英文和繁体分别使用 `/en/`、`/zh-Hant/` 前缀。URL 决定 SSR/首屏语言，禁止共用可变的服务端全局语言实例。新增页面要同时补 canonical、hreflang、sitemap、元信息和语言导航。

`README.md` 默认简体，`.en.md` 和 `.zh-Hant.md` 是对等文档；三份互链。公开 SDK、Linux、官网、插件及模板说明同步维护；历史发布和验收记录保持原文。翻译代码注释或示例文案时，不改变 API 标识、字符串协议、路径和命令。对应语言的产品截图放在 `docs/screenshots/<locale>/`，营销示意与真实数据截图要区分。

## 验证

主仓运行 `npm run typecheck`、`npm test`、`npm run build`，再运行 `npm exec -- playwright test tests/i18n.spec.ts`。插件仓运行 `npm run typecheck`、`npm test`、构建与真实宿主验证。官网运行 `pnpm verify`、`pnpm format:check`、`pnpm test:browser`。

语言回归应覆盖：系统映射、缺词与插值、已有配置、持久化、多窗口同步、输入保留、三语搜索、旧插件、九页 SSR/SEO 与窄屏。不要将 macOS 本地验收描述为 Windows/Linux 原生验收或线上发布。
